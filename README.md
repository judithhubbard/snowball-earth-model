# Snowball Earth Model

An interactive latitude-band energy balance model of Earth's climate with land and ocean, an ice–albedo feedback, and a slow carbon cycle (volcanic CO₂ input, silicate weathering, an ocean CO₂ reservoir). Built for EAS 3010.

Open `index.html` in a browser, or use the GitHub Pages site.

- Adjust the Sun, CO₂, volcanic rate, flood-basalt cover, and continent layout
- Watch the ice line respond on a rotating globe, with temperature by latitude, time series, and the temperature–CO₂ hysteresis loop
- Two scenarios: Modern Earth, and a Neoproterozoic Snowball cycle

Model equations and all parameter values are listed at the bottom of the page. The only external dependency is MathJax (loaded from cdnjs) for rendering the equations.
